# Attendance Tracker

Track class attendance with the Persian (Jalali) calendar — offline, no sign-up.

## 🚀 Use It

**→ [tiredasfuck.github.io/attendance-tracker](https://tiredasfuck.github.io/attendance-tracker/)**

## 📲 Install as an App

1. Open the link above in **Chrome** (Android) or **Safari** (iOS)
2. Tap **"Install app"** (Android) or **"Add to Home Screen"** (iOS)
3. Done — works fully offline

## ✨ What It Does

- Add courses with weekly schedule (day + week type: every / odd / even)
- Quick-mark today's classes as **Present** or **Absent**
- Monthly Jalali calendar view per course
- Per-course and per-session notes
- Attendance rate & stats per course
- JSON backup & restore, CSV export
